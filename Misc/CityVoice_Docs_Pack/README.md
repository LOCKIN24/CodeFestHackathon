# 厝邊聲援 CityVoice

> 用你熟悉的語言，找到城市的幫忙。

文件狀態：開發規劃稿（2026-10-29）。本文件描述**計畫與驗收條件**，不代表功能、模型、語言或裝置已通過測試。

## 1. 專案概述

CityVoice 是面向臺灣高齡者、新住民，以及數位能力或設備受限市民的**語音優先、多語言、市政服務導航微服務**。目標不是取代政府或做通用聊天，而是讓使用者以熟悉的語言說出需求、確認系統理解的內容、取得可追溯的官方資訊、知道下一步；遇到困難時，能將**不含敏感資訊**的任務摘要交給親友或真人服務窗口。

**核心承諾：無論語音、LLM、TTS 是否可用，都要有完整、易用的文字／選單流程。** 語音是重點體驗，不應成為排除聽障者、無法說話者或舊手機使用者的門檻。

### 目標族群與使用原則

- 臺灣高齡者：可自行選臺灣華語／經驗證的台語，不把年齡等同於語言或能力。
- 新住民：優先研究越南語，再視實測擴及印尼語；不預設中文程度。
- 舊手機、網路不穩或不想使用語音的使用者：基本文字模式提供同一市政任務。
- 所有人：可選語言、修改辨識結果、查看資料來源、隨時取消或求助。

## 2. MVP：只完成一個任務，但走完全部步驟

**示範主流程：**

1. 從 TownPass／城市通進入 CityVoice。
2. 按麥克風說「我想找人教我用手機」（**已通過實機驗證時**），或直接輸入文字／點選「找手機使用協助」。
3. 顯示 STT 逐字稿，讓使用者確認或修正（文字與選單路徑可跳過）。
4. 顯示受控的候選服務意圖，讓使用者確認。
5. 請使用者手動選行政區；預設不要求定位。
6. 從**已審核且合法使用的官方公開資料**取出符合的服務、來源及資料日期。沒有可確認的當期時段，就明確顯示「目前沒有可確認的時段」。
7. 用白話固定模板呈現「下一步」，不讓 LLM 編造地點、時間、資格、電話或連結。
8. 使用者可預覽、出示或分享「城市接力卡」，交給親友協助。
9. 若 AI 不可用，保留進度、切回 Basic Mode，仍能完成步驟 4–8。

**範圍控制：** MVP 不實作正式政府登入、身分驗證、送件、付款、預約、授權代辦、雲端 LLM、全語種任意語音聊天。

## 3. 相較一般 AI 聊天機器人的差異

- **語音優先而非語音限定**：文字、按鈕、讀屏具有完整功能。
- **臺灣在地語言問題**：研究台語／華語混用及新住民常用語言；只宣稱實測通過的能力。
- **可信的市政下一步**：LLM 只能提出受限的服務分類建議，行政事實由可驗證資料與固定模板提供。
- **人際接力**：安全的任務卡可讓親友協助，不傳輸密碼、證號、音訊或對話逐字稿。
- **設備平權**：高階機可執行本機模型；舊手機可不載入模型完成主流程。

## 5. 技術方向（候選，非已實作）

| 層 | 建議 | 關鍵條件 |
|---|---|---|
| Host App | Flutter / Dart（TownPass） | 保持與官方架構相容 |
| 微服務 UI | Vue 3 / TypeScript / Vite（TownPass-Services） | 以官方已支援的進入方式及橋接機制為準 |
| Native Bridge | Flutter WebView ↔ Vue，版本化訊息 | 來源白名單、schema 驗證、timeout、最小權限 |
| STT | whisper.cpp、sherpa-onnx、台語專用 ASR 候選 | 語言、離線、iOS/Android、授權、延遲與 RAM 實測 |
| LLM | 小型可量化模型＋合規本地 runtime 候選 | 只做白名單意圖分類；不可在遠端推論 |
| TTS | 系統本地 TTS、合規離線模型或固定授權錄音 | 語言／聲音／飛航模式實測，不可假設台語已支援 |
| 資料 | 審核後資料快照＋官方連結 | 合法開放資料、版本、來源、有效期限 |
| 接力 | QR／可複製文字 | 只含非敏感且公開可分享的欄位 |

**請勿把 SEA-LION、Breeze、Whisper 或任何模型寫成「已選定且已支援台語、越南語」。** 一切須經真機及授權評估後才能啟用。模型大小、峰值記憶體、延遲及相容性皆列為測試結果，而非預設事實。

### 三級模式

- **Full AI**：本機 STT + 本機受限意圖模型 + 可用的本機 TTS。僅在測試機型與語言驗收通過後開放。
- **Light Voice**：較小的本機 STT + 固定分類／選單，不依賴大型 LLM。
- **Basic**：無模型的完整文字及圖示流程。最先完成、也是最低設備支援基線。

切換失敗時須保留已確認任務狀態；當作業系統直接終止 App，重啟後至少恢復已保存的非敏感狀態。不得聲稱已驗證所有舊手機型號。

## 6. 開發環境

**先記錄官方專案的 commit／tag 與各工具版本，避免主分支更新影響測試。** 以下命令是既有 repository 的入門指令；不代表目前機器已成功編譯。

### Flutter TownPass

```bash
git clone https://github.com/taipei-doit/TownPass.git
cd TownPass
# 依據 .fvmrc 安裝／選用相容 Flutter（目前曾標示 3.47.6，請以 checkout 版本為準）
flutter pub get
dart run build_runner build
flutter run
```

iOS：需要 macOS、Xcode、iOS 裝置或 Simulator，以及 Apple signing／provisioning；**本機模型效能與離線能力必須用實機測**。

### TownPass-Services

```bash
git clone https://github.com/taipei-doit/TownPass-Services.git
cd TownPass-Services
pnpm install
pnpm dev
pnpm build
```

原始專案可能含不符合本次競賽的商業地圖套件或其他依賴；不能假設原有套件自然取得參賽合規資格。

### 開發前的驗證順序

1. 兩個 upstream repo 在至少一名成員的設備上可啟動。
2. 在官方允許的路徑中完成 Vue → Flutter → Vue 最小橋接；記錄成功或限制。
3. 以飛航模式完全重啟 App，確認頁面與預載資料可讀（不要只測已開啟的 WebView）。
4. 在一支真實 iPhone 完成離線 STT；記錄語種、音長、延遲、設備、記憶體。
5. 在同一支設備單獨測試本機 LLM；再測整體記憶體壓力。
6. 根據 `PRIORITIES.md` 的 Go/No-Go 截止時間決定展示功能。

## 8. 安全資料契約

模型的服務意圖輸出**只能是候選，且必須經程式驗證與使用者確認**。例如：

```json
{"version":1,"intent":"digital_help","district":null}
```

`intent` 必須在允許清單；無效或不確定時退回固定選單；LLM 不得自選官方網址、資格或服務時間。

服務資料範例（schema，不是實際據點）：

```json
{
  "id":"sample-only",
  "service_type":"digital_help",
  "district":"待填",
  "name":"待官方來源確認",
  "phone":null,
  "address":null,
  "sessions":[],
  "source_url":null,
  "source_published_at":null,
  "retrieved_at":null,
  "valid_until":null,
  "license":"待確認",
  "review_status":"pending"
}
```

未審核、無資料日期或已逾期者不得被呈現為「目前可預約／可前往」。

接力卡只允許：`schemaVersion`, `serviceId`, `district`, `completedStepIds`, `nextStepId`, `sourceUrl`, `dataDate`, `notice`；產生前讓使用者預覽；不得包含姓名、身分證號、電話、密碼、token、語音、逐字稿或自由輸入內容；QR 不是加密也不是代理授權。

## 9. 功能驗收標準（建議值，實測後可調）

- 完成一條完整市政任務：TownPass 入口 → 輸入／選單 → 需求確認 → 選區 → 有來源的結果 → 下一步 → 接力卡。
- 文字／Basic Mode 不依賴麥克風、LLM、TTS 或登入。
- 有語音時：iPhone 飛航模式可辨識新句子，文字可修改並確認；失敗可立即切文字。
- 有 LLM 時：飛航模式可推論新句子，只產生白名單意圖；行政資料不由 LLM 任意產生。
- 200% 字級、適當對比、可讀屏、可操作返回與取消；避免需長按或限時的操作。
- 任何服務卡片顯示來源、資料日期、過期／待確認狀態；沒有有效資料就明確告知。
- 一支 iPhone 完成多次全流程測試；Android／舊手機展示範圍由實測決定。
- 檢查第三方軟體、字體、模型權重與資料授權，產生來源／版本清單。

## 10. 工作方式與交付文件

- **開發優先順序、Go/No-Go 和細項驗收：**讀 `PRIORITIES.md`。
- **AI coding agents／自動化代理必須遵守：**讀 `AGENTS.md`。
- 一項任務一個 issue／branch／PR；小步提交，避免同時重構兩個 upstream repo。
- 每個 PR 附：變更內容、對應需求 ID、設備及測試證據、回退方案、依賴和授權變化。
- 未經實測的語言與 AI 模式不能在 UI 或 Demo 中宣稱可用。
- 如發現與官方競賽新規則衝突，停止相關工作、標記 blocker，由隊長確認再繼續。
