# TownPass hackathon workspace

The integrated Flutter app is in **[TownPass](TownPass/README.md)**. It includes the milk-service Studio UI, family pickup planning, school-to-home store suggestions, local mock services, and the original 3D Milk Passport. The existing AI assistant and four-tab navigation remain available.

- [App setup, operation and checks](TownPass/README.md)
- [Passport renderer source and build](passport-renderer/README.md)
- [Vue service project](TownPass-Services/README.md)

The hackathon build may use fictional profiles and local service providers. Provider configuration and reset tools are in the operator settings. Local mock results are not sent to government systems. Existing external links and live store search retain their network requirements.
